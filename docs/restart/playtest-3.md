## Selected response

Actor-specific, revision-specific observed comparisons now enter the same HF context for demonstrations and decisions. Controlled consumer tests establish method differences; they are not an uncontrolled playthrough.

The uncontrolled trace still selected meals and personal plans instead of help after that fix. Native responsibility purposes and consent are therefore being integrated separately.

The UI increment makes returned objects and the completed afternoon the payoff. It adds an optional chosen pause rather than requiring the player to finish another queue for a closing scene. Final source-unread play remains required after these changes stabilize.

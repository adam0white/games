# Plain English

Use full sentences for instructions and descriptions. Include articles and verbs. Short button labels can name an action.

Say literally what happens. Use the same name for each thing. Prefer familiar words. Aim for grade 7 instructions. Dialogue can be richer, but must be grammatical.

Introduce one idea at a time. Explain a game term when it first appears. Describe uncertain state clearly, such as “Sam looks tired.” Cut words that do not help the player.

Preserve culture, names, meaning, rules and difficulty. Do not translate Turkish terms without the owner's decision.

Keep replay data and historical text unchanged. A presentation-only rewrite may clarify that text when displayed. Reading checks measure heuristic source candidates, including internal and lab strings. They do not establish a reading grade or replace inspection.

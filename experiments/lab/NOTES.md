# Lab experiments log

Wildcard experiments on the two focus games, Lantern and Ant Promotion. Each experiment is a static directory `experiments/lab/<name>/`, served at `/lab/<name>/`, and tests one idea the main lines would not try. Nothing here changes `experiments/lantern/` or `experiments/ant-promotion/`.

Rules for this directory:

- An experiment imports the main game's `sim.js` or `art.js` by relative path when it only changes the look, so graduating it is a small change. An experiment that changes rules keeps its own copy of the rules.
- Each experiment gets one row below: what was tried, what the checks showed, and a verdict (graduate, keep testing, or drop).
- At most one question per experiment goes to the tester's notes page.

## Follow-ups

- 2026-11-23, `lantern-3d`: the main Lantern rules gained abilities (boost, slow water, size, magnet, flare) after this page was written, and the page took them without drawing them. Fixed: each ability is a coloured glow with a reflection, the boat model follows the size ability, the percentage and dawn use the rules' own `progress`, and each pickup has its sound and line. Checked on main `cc1113e3` in WebKit with the iPhone 13 profile: all five drawn, all five picked up, no script errors. The tower mode and the looks shop of the main page are not in the 3D page.
- 2026-11-23: the three lab bots (`ant-wilds`, `ant-nemesis`, `ant-nest`) and the 12 `workers/lab-ai` tests pass on main `cc1113e3`, after the Ant Promotion changes of PRs 51 and 59. The numbers in the table above were measured before those PRs.
- Rule for look-only experiments: they import the main game's rules, so a rules change can outrun them. Re-run the browser check for `lantern-3d` after every Lantern rules merge.
- 2026-11-24, outcomes of batch one, from the tester's answers (notes #83 to #86) and the main games:
  - `lantern-3d`: graduated. The tester asked to switch between 2D and 3D (and for a first-person view, notes #158 and #159); the Lantern thread is adding the views to the main game.
  - `ant-nemesis`: graduated. The tester said yes to keeping the rival; it is in Ant Promotion. This page stays as the first version.
  - `ant-wilds`: graduated, with a lesson. Animals hunting animals is in Ant Promotion as the Wild rules. The tester's answer here was that it did not work: at level 1 nothing near the player is 2 levels above anything else, so no hunt is on screen in the first minute. The main game has since made hunters try harder (its note #106). A rule the player cannot see in the first minute reads as a bug.
  - `ant-nest`: parked. The tester did not notice the ants choosing for themselves, which is the idea under test. Adam doubted the fit. Not graduated; the page stays. It keeps its own in-world first-time hint (a finger dragging down the soil at the entrance) instead of the kit's `path` hint, because it shows the exact place to drag.

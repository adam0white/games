# Native candidate testability — 2026-10-16

Question: can an autonomous coding agent meaningfully test changes? **Yes for bounded changes in the six main candidates below; confidence differs sharply by existing harness.** Native language and project age alone do not answer this. The inspected harnesses make Wesnoth, OpenTTD, FreeCol, Mindustry and Endless Sky credible autonomous edit/test targets after environment setup. Naev needs more harness work before trusting behavior changes.

This is source inspection, not a successful game build or playtest. Commands below reproduce upstream CI/targets after documented dependencies are present. They were **not run** here. Linux presets are labeled as such and are not claimed to work unchanged on this Mac. Sources were fetched at the exact pins in `upstream-refs-2026-10-16.json`. No system packages were installed. Local tool check found Java, CMake and Ninja; Ant and Meson were absent.

## What would establish autonomous readiness

A selection spike should first reproduce one upstream test on the chosen machine or CI image. Then add one scenario at the intended integration boundary and demonstrate that a deliberate broken behavior makes it fail. Only then add the HF bridge. Preserve actor snapshots, host state, RNG state and versioned observations/actions in saves. Run identical external events for the HF and baseline controls. These are proposed acceptance checks, not existing upstream features.

HF is currently a pinned npm dependency in this project. None of these inspected native hosts demonstrates direct released-HF integration. A child Node process with versioned messages is a plausible adapter, not a verified solution; ordering, latency, failure handling, serialization and replay need an actual spike. An embedded rewrite or translation of HF would violate the existing package boundary.

Build feedback can prove compilation and selected state transitions. Headless tests do not prove readable screens, useful controls, player understanding, or enjoyable game feel. Those still require visible interaction and Adam’s acceptance.

For a bounded proving experiment, Wesnoth offers the best inspected authored scenario and evidence machinery. FreeCol is a credible people/negotiation candidate with explicitly headless model tests. Endless Sky has more actual integration automation than its real-time presentation suggests. Mindustry and OpenTTD have strong technical feedback loops but weaker fit for proving human agency without adding a new social design. Naev is feasible, but its inspected tests leave more behavior harness work to us.

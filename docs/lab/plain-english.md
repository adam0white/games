# Plain English

Use full sentences for instructions and descriptions. Include articles and verbs. Short button labels can name an action.

Say literally what happens. Use the same name for each thing. Prefer familiar words. Aim for grade 7 instructions. Dialogue can be richer, but must be grammatical.

Introduce one idea at a time. Explain a game term when it first appears. Describe uncertain state clearly, such as “Sam looks tired.” Cut words that do not help the player.

Preserve the setting, places, personal names, meaning, rules and difficulty. Every sentence must be understandable without Turkish. Use English for common nouns. Keep at most two flavour words and explain each within its sentence on first use. Faith stays quiet background; source its wording from the framework's research/ directory and do not invent rulings.

Keep historical export files unchanged. Rewrite current player text at its source. Prove rule-state equivalence with explicit prose-field normalization and seeded full runs. Keep IDs, semantic cues, numbers and non-prose HF state exact. A copied game observation in a witnessed memory is prose; its identity, tags, salience and other fields must stay exact. Current exports must replay. If an older export no longer matches, explain that the player should start a new game. Reading checks measure heuristic source candidates, including internal and lab strings. They do not establish a reading grade or replace inspection.

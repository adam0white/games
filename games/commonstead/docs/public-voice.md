# Public words

A public introduction uses the resident’s current public work assignment. It does not reveal a private story. Known occupations have finite authored words. An unknown assignment keeps its narrator description and cannot borrow another person’s biography.

An invitation waits for the current action and carried delivery. Ordinary travel brings speakers together. Each speaker receives a separate HF offer with the still-valid retained work, existing body choices and quiet as alternatives. Choosing retained work uses its real start once and records no new speech. Actual choice, matching finish and listener attention remain separate records. A transport failure, pause or cancellation is not a resident’s refusal.

A work reply dates the actual request and does not promise acceptance. A Yield response needs the exact native completed Yield, its person, route pair and start offer. Hearing the current report does not establish earlier direct witnessing or agreement.

An optional closing word uses a matching completed native result, explicitly dated, or an identified current public work fact. Narrator ending facts remain readable without time passing. “Continue this workshop to ask” records the real same-Run continuation before checking the new invitation. A refused invitation does not undo that continuation.

New state appears only after an accepted public-exchange command. Current-version schema12 files without that command keep their original input path. Older HF files may refuse before adoption. Unsupported outgoing publication still refuses before writes. Whole-game acceptance, final compatibility files and final native/durable proofs remain separate gates.

The short yard uses the ordinary fifteen-unit arrival boundary for public meetings. Long meetings retain their five-unit boundary. Rejected build requests keep the native invitation and prior work owner; a replay-derived refusal receipt prevents the rejected input from replacing a valid earlier work source. Edited refusal receipts are not import authority.
